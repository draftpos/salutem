## 📌 Overview

**Salutem Dynamic Terminology & Branding Suite** tailors standard Odoo commercial workflows to membership organizations, healthcare providers, and cooperative benefit funds. It provides clean UI settings to dynamically override standard ERP vocabulary without modifying core database schemas or breaking third-party module integrations.

---

## ✨ Key Features

### 1. 🔄 Dynamic Terminology Translations
- Automatically transforms standard ERP terminology into membership-centric nomenclature:
  - **Customers** ➔ **Members**
  - **Sales / Orders** ➔ **Contributions / Policies**
  - **Products / Services** ➔ **Subscription Packages / Benefit Plans**

### 2. ⚙️ Centralized Settings Control
- Toggle and configure customized label dictionaries directly from Odoo General Settings (`views/res_config_settings_views.xml`).
- Instant UI refresh across forms, tree views, kanban cards, and reports.

### 3. 🛡️ Non-Invasive Extensibility
- Clean override layer that preserves native Odoo field names, APIs, and ORM business logic.
